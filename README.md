This repository contains my work for the 9th-grade Informatics class, including:
                    - Classwork: Problems solved in class.
                    - Theory and exercises: Example problems based on a type of problems (e.g. Divisibility) and some practice problems.
                    - Olympiad Prep: Advanced problems from the Informatics Olympiad or problems that might appear on the olympiad.
Many of the problems solved here are from pbinfo and similar websites.
